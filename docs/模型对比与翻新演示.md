# 从旧机进厂到翻新出厂

展会上的采购商通常能一眼认出重喷过的漆。更值得用动画回答的问题是，送进来的旧机究竟查过哪里，为什么修或换，原来的部件怎样装回去。整机新旧对比用来抓住注意力，中段用一个能被观众追踪的原件讲清楚处置过程。

## 两台挖机各自擅长什么

| 本轮打开 Blender 实查的内容 | Phil Rivera 参考机 | 永鸿教学机 |
|---|---|---|
| 外观与旧化 | 配重下沿积垢、斗杆与斗的刮擦，以及履带接触面的材料差异清楚。原生材质把颜色、粗糙度、金属度和法线分别接入。没有找到独立的干净底漆或污渍遮罩。 | 可分别调整积泥和漆面旧化。机身与驾驶室轮廓仍方正，大臂软管弯曲、下车侧架配色和铲斗磨损分布仍需对照实机照片细修。 |
| 动作 | 118 个网格，一条 35 秒动作。动臂、斗杆、斗、缸和多段软管能一起随动，后段有履带和轮件运动。原生 Blender 默认播放范围只覆盖 1–250 帧。 | 原整机场景有冷却舱开合、工作装置联动、检修盖开合。复核覆盖 14 个采样姿态，原场景还可逐件检查。 |
| 打开后看什么 | 能辨认驾驶室内饰；未找到可逐件抽出的发动机、泵阀或缸内零件。已发现的动作未展示真实维修过程。 | 可从原有六缸及可拆管段教学研究中挑选有依据的章节。七件项目自建 STEP 与基线对应。每段拆装应单独核查，实机结论需要检验记录。 |

参考机作者用多台实车作设计参考；他的作品可借鉴磨损落点、轮廓和软管的运动节奏。作者资料见 [Phil Rivera 作品页](https://philrivera.net/projects/g2xobL)。使用商业模型制作成片时应先核实取得该资产所适用的平台许可。[Fab Standard License](https://www.fab.com/eula)

## Windows 打开与切换

从 [本版下载页](https://github.com/zackzhang538-stack/yhrm-reman-excavator-restart/releases/tag/studio-v1.0.0) 下载整机 `YHRM-teaching-excavator-studio-v1.blend`。验证使用 Blender 5.3.0。打开时是驾驶室侧摄影棚的第 358 帧，按 F12 可看到当前状态。可在场景属性底部的“自定义属性”调整以下两项，再按 F12 比较。材质预览或渲染模式可以观察表面，实体模式主要用来查几何。

| 整机状态 | field_soil（泥污） | paint_wear（漆损） | 应看到的变化 |
|---|---:|---:|---|
| 旧机进厂 | 0.94 | 0.90 | 履带板、斗面与侧围下部积泥，涂层有局部磨损 |
| 清洗后 | 0 | 0.90 | 泥污消退，掉漆仍在原件上 |
| 翻新外观（打开默认） | 0 | 0 | 工作装置与侧围恢复涂装，斗齿、杆面及履带接触面仍有本身的材质 |

两项都能插关键帧。整机比较使用同一套几何、姿态、灯光和相机。末态表达翻新后的外观。外观旧化的分布属于教学设定，无法推导某台实机的故障、间隙或寿命。

## 拆检镜头怎样接上

本轮以台架上的后降管中段作局部动作试验。进场时先认识这段管和它的法兰；清洗后看见原有漆损。螺钉旋退、上下段沿轴线分离，镜头才看得到封槽和加工面。回装时让观众认出同一个接口；翻新漆只对外部涂装表面起作用。正式片中，判定密封件应否更换，需要有具体的检查依据。车上全行程拆除、工装承载、压力和泄漏性能需另有证据。

最后回到进场时的整机机位，重复举臂和收斗。这样观众能够比较翻新后的外观和动作。工厂实际放行结果可以接真实试机画面和记录。
