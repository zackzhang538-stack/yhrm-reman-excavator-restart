# 重启流程

## 先完成第一轮可审阅模型

| 顺序 | 工作与产物 | 怎么验收 |
|---|---|---|
| 1 | 确认整机轮廓、吨位档位、参考结构、坐标和单位。将架构、材质与品牌定为各自可修改的层 | 从四视图查车身与履带边界。注明每项尺寸取自实测、可追踪资料或教学假设 |
| 2 | 给各系统建零件清单与安装接口表。优先摆下车架、上车架、舱盖、驾驶室、配重、发动机、泵阀与动臂 | 先用简化体检查承力路径、舱门、上下机、工具和拆件空间。有问题先改整体 |
| 3 | 选择来源最完整的总成，确定装态、打开、可维修拆检、复位。每个件独立建模，保留机上原装矩阵 | 确认锁定、止脱、密封面、轴线、支承。复查扫掠及极限位；用实际需要的量具、工具或包络核空间 |
| 4 | 整机与各独立总成核对后合并。固定来源批次、零件 ID、坐标、版本和合装报告 | 从独立会话重开，查链接、装位、变换和材料。外形与内部要能逐层点选 |
| 5 | 在已验证的结构上做原生动作。先出低成本预览，通过后再渲主要镜头 | 首两秒识别对象，能看清在哪、怎么脱开、检查哪里、为什么处置、怎样复位，再接验证。结构展开和可执行维修动作分别标注 |

优先把整机大关系跑通，再为每个总成补细节。首轮交付一份可点选的整机工作台、系统/接口/缺项表，以及一个来源完整的拆检复装链。随后逐项完成全机内部模型和再制造影片。局部路径通过或网格数量都不能折算为整机完成率。

历史范围有 22 个系统，可以用作拆分工作量的参考。重开时从实际模型建立匹配的登记。每条记录应有系统、零件、来源版次、CAD/网格摘要、连接基准、装态、受影响的动作、核验类型、通过范围及待验项。

## 几何与影片怎么接

按入场评估、清洗拆解、检测判定、修复或换新、表面处理及复验、组装、性能检测、交付回访组织章节。由实物工单和适用标准确认顺序、判据与验收。暂无同号工单时，明确标注教学示意。

每段镜头只追一条因果，例如原位看到磨损面、拆开取得接触面、量具接触、复验并落座。给章内机械动作足够的观看时间，影片时长从逐章镜头算。先验证白模动作和相机，再渲细节材质并同步声音。最终核试听、静音可读、关键帧和全段解码。
