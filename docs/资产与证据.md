# 资产与证据

## 一份整机

Release 中的 `YHRM-excavator-teaching-assembly-80a7.blend` 是整机合装冻结件，保留后续独立 S18 维修研究分支之前的主场景。原件 SHA-256 为：

```text
80a792514b4a4baaafee2d658da0ed344efbbd3a73f8a5736b18bd1194d5b7e9
```

已对六缸 18 件局部网格的坐标更正及 14 个整机姿态做核对。本次交接另在新目录重开，确认原生对象、场景和资源依赖。具体范围见 [原机验收](../evidence/whole-machine-acceptance.json) 和 [移位重开](../evidence/reopen.json)。

已核范围不能说明所有总成正确。全机仍有结构、动作、力学、液压、检修、密封和实机试验待核。整机文件应命名为教学基线，开新副本后复核关键子部件。

## CAD 来源

上一轮使用 CAD 实体和 STEP 作为几何中间件，有些配合可用实体布尔、孔和轴线检查。项目中的自建 STEP、网格和原生场景来自参考资料加工程假设。经销商目录、标准、专利和制造商技术说明可以供查证。当前没有确认到足以认定为适用整机的原厂 CAD 原件，也没有对局部候选作制造放行。本次保留 7 件与整机逐件对上的项目自建 STEP。包含加长曲轴、第三缸连杆体和盖、上瓦和下瓦、两只定位套。核查三项：原始 STEP 的文件摘要、有效实体读回、源 STL 和整机网格局部坐标的双向顶点距离。最大差约 0.0000153 mm，反映网格对账精度。使用范围仍是教学和重建，制造公差、载荷和全系统试验另核。[CAD 对账](../evidence/cad-origin-and-native-match.json)

早期短版曲轴与当前整机安装的加长曲轴有明确版本差异。仓库内曲轴文件采用相符的加长版。两份 TE 器件的原厂 STEP 已核对其下载包来源，与当前教学整机无已证实的零件关联。可从官方页面索引，原文件留在本机。TE 对网站资料二次分发有书面授权要求。[壳体](https://www.te.com/en/product-DT04-2P-E005.html) · [楔锁](https://www.te.com/en/product-W2P-P004.html) · [TE 使用条款](https://www.te.com/en/policies-agreements/terms-of-use-te-com.html)

S18 箱侧两端接头 v01 至 v03 的实体输出经报告确认有套筒干涉，已移至本机废纸篓。v04 的局部验证是独立后续研究，供原项目追踪。

## 使用方法

把 Release 的 Blender 文件下载到本地。用 Blender 5.3 打开。检查主场景、对象 Outliner、帧 1 的整机、属具动作和内部总成。保存为新的工作副本。完整的装配身份、工艺合同与媒体索引须按新的母机重建。历史登记跨过多个候选，容易造成错配。

如需在新电脑验证，可按 Release 的 SHA256SUMS 核对，再运行：

```sh
blender -b --disable-autoexec /path/to/YHRM-excavator-teaching-assembly-80a7.blend \
  --python tools/inspect_blend.py
```
