# 复盘与案例

## 机械建模的返工

- 早期小零件先做细，机舱、承力与检修边界还在变，最后出现管线出机壳、工具进不去、零件无法撤离。首轮先锁外形和安装基准，用粗模型过关后再细化。
- 同一个装配文件可能混用不同时期的零件。曾发现六缸 18 个关联件的网格本地 Z 基准偏了 73.5 mm。修正后按身份、装位和关键帧逐项复查。重启前先统一原点、轴向和单位，更新零件时同步复查接合关系。
- 扫过若干帧、热态未算、仅比较新增材料，各自只回答局部问题。一次铲斗检查只对新增材料做多姿态筛查，完整实体复核后来在临界闭斗状态发现相交。今后把称作“通过”的对象、输入、范围和限制写进验收。
- S18 箱侧硬管直斜拉会撞箱。分段斜退、垂升、横移的局部候选通过连续几何核验。接持、放油、耐漏与实际抬箱仍待证。保留这个判断方法作为经验，失效几何不作为重启资产。
- 一轮本机重开核验由 20.41 秒降到 9.69 秒，另一个检查由 14.75 秒降到 9.46 秒。优化牵涉共享网格、源哈希和读文件缓存，逐实例身份与变换照常查。这两组是局部测量，不能外推整个项目工期。

## 影片差距

旧 36 秒六缸总览前约 6 秒主要看外壳，最大展开时主体约占五分之一画宽，内件看不清。曲轴段从量轴颈切到换下瓦，观众无法根据画面理解换件依据。大片均匀银灰使铸件、机加工面和轴瓦区分不足。随后用冻结结构重拍，活塞、连杆、缸套和缸盖接缝可辨，工艺因果仍需同一件零件在检查、判定和复验镜头中贯通。

工程机械案例里可以迁移三件事。

1. 先用整机定位总成，再切接合面和运动件。EFFE 的项目方法包含半透明整机、爆炸结构以及与液压缸、回转和行走动作的关联。[挖掘机液压动画案例](https://3danimation.in/projects/3d-product-animation-for-excavator/)
2. 先做白模预演固定场景、机位和运动，再做照明、材质和连续渲染。太阳鸽鸽公开简介明确以 Blender 与 Hyper3D MCP 做白模预演，本项目未取得对方原 Skill。[作者的导演预演说明](https://www.youtube.com/watch?v=Feb1FAFjXpc)
3. Blender 工程、动作与复查证据一起留下。程序化相机和核验可参考开源实现。当前工作有本机 Blender；替换控制插件不能单独解决工艺与叙事问题。[Codex-and-Blender 公开实现](https://github.com/danielsobrado/Codex-and-Blender)
