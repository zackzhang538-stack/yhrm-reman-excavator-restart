# 永鸿教学机 · 入场、预清洗与待拆检

Windows 本轮先打开 `YHRM-teaching-excavator-intake-v1_1.blend`，另存工作副本。工程默认是入场状态，第 358 帧。按 F12 看入场渲染。下载页有同一机位的整机、驾驶室与配重、局部污损三张对照图。[本版整机与审阅图](https://github.com/zackzhang538-stack/yhrm-reman-excavator-restart/releases/tag/studio-v1.1.0)

## 两台模型分别做过什么

外部参考机只在本机研究过动臂表面、材质层次、工作装置与软管随动。动臂外侧做过浮泥、洗净、局部漆面试色。永鸿 1.0 则核对原网格和动作，主要修改材质、摄影棚和镜头。两份工程各自独立，公开交付的整机由永鸿原资产派生。参考机值得借鉴的是接地与摩擦处的磨痕、不同表面的光泽和软管弯曲时连续的形态。[参考作者作品](https://philrivera.net/projects/g2xobL)

本版修改了永鸿原生几何。驾驶室的前风挡、前柱、角窗与密封条一起调整倾角，顶板略起拱。后配重保留原后标平面、孔和承座，后部两肩收弧。前风挡与坐垫造型参考了项目照片，配重为保留安装接口的教学造型。项目尚无原厂外形测绘、保护结构强度、配重质量和整机稳定性的验证。中部检修舱仍较平直。

## 切换预清洗前后

在“场景属性 → 自定义属性”中设置下表，保持机器姿态、灯光与机位一致，再按 F12。五项均可插关键帧。整机比较展示的是表面状态。正式洗车镜头的停机与工作装置位置按现场规程另行布置。

| 参数 | 旧机入场 | 预清洗后、待拆检 | 画面依据 |
|---|---:|---:|---|
| field_soil | 0.94 | 0 | 履带、斗体和下部围板的可洗泥污 |
| airborne_dust | 0.85 | 0 | 三处朝上检修盖的积灰 |
| joint_oily_grime | 0.85 | 0 | 一只液压软管扣压套的局部油泥，油迹来源待检查 |
| paint_wear | 0.90 | 0.90 | 原有掉漆继续留在原件上 |
| panel_dent | 1 | 1 | 同一侧检修板的浅凹保留。示例最大凹深约 14 mm，用于观察 |

以上数值是动画旋钮与建模参数。观众应能看到泥污被洗去，漆损、浅凹或磨痕在原来的位置露出来。后续如要表达板件整形或涂装，先给出检查和处置依据，再改变相应的几何或材质。

## 宣传片怎样讲清再制造

1. 入场记录整机和总成身份，拍下原有痕迹及需检查的位置。
2. 外部预清洗后进入拆解。对照同一台机上的安装位置，分件清洗、检查、测量并留存结果。
3. 镜头跟住一个原件与同一工作面。按适用标准、维修资料或工艺要求判断去向。合格且允许继续使用的件留用，可修件修复后复检，超限或规定应换的件更换。
4. 把通过检验的零件装回总成，复装整机。表面处理和涂装只落在工艺要求的位置，保护密封面和工作面。
5. 试机与性能检验按适用规程进行。教学机可以演示举臂和收斗，实机性能结论需要相应记录，合格后方可表达放行与交付。

卡特彼勒公开实例给出了旧件拆解、清洗、检查、恢复、再装配及性能测试的顺序。土方机械再制造零部件可参考 GB/T 41101.2-2021。本项目的机型参数、验收和放行依据应另行核实。[Cat 原厂工艺](https://www.cat.com/en_US/products/new/parts/reman/the-remanufacturing-process.html) · [国家标准资料](https://std.samr.gov.cn/gb/search/gbDetailed?id=D4BEFFF4EA0BB241E05397BE0A0AF581)
